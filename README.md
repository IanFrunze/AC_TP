# 💻AC_TP💽

Este repositório foi criado no ambito de trabalho da disciplina "2226, Arquitetura de Computadores" para o Grupo 02 da turma 24D do curso "2191, LEIC" do "ISEL", com o objetivo de transferir ficheiros entre membros para trabalhos de laboratório e trabalhos práticos.

A unidade curricular Arquitetura de Computadores tem como principal objetivo dotar os alunos dos conhecimentos necessários à compreensão do funcionamento de um sistema computacional, tanto da perspetiva de programador como de projetista de hardware.

A arquitetura usada como objeto de estudo na disciplina, é uma arquitetura baseada em ARM com o processador P16.
